Add an hourly check

The page reads stepup-watchdog/checks.json in the browser. No build, no keys, no private APIs. Append one object per person inside checks, commit, and refresh after GitHub Pages updates.

  1. Use one check_time_ct for the pass, in Central Time: YYYY-MM-DD HH:MM.
  2. steps is the Today total in the app, not the change since last hour.
  3. last_update is when StepUp says that person last synced, in the same clock format when you have it.
  4. Leave delta_steps, hours_since_prev, steps_per_hour, and flag blank. This page calculates them.

Check about once an hour between 6pm and midnight. A long gap can hide a jump, because the rules use the time between our rows. A new name still shows up if it is not in people yet.

Example row

{
  "check_time_ct": "2026-10-12 19:00",
  "person": "Alyssa Fogerty",
  "steps": 32800,
  "last_update": "2026-10-12 18:57",
  "delta_steps": null,
  "hours_since_prev": null,
  "steps_per_hour": null,
  "flag": "",
  "notes": ""
}

check_time_ctWhen you looked. America/Chicago.
personFull name, matching the board when you can.
stepsToday total from StepUp.
last_updateThe app’s last sync time.
delta_stepsOptional. Steps minus the previous check.
hours_since_prevOptional. Hours between those checks.
steps_per_hourOptional. Delta divided by hours.
flagOptional. Leave blank. The page sets amber or red.
notesAnything you want to remember about that look.
