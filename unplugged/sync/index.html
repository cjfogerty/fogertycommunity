Parameters: name, date (YYYY-MM-DD), total, social, general (or other), messaging, healthy, pickups, notifications, all minutes. Add &auto=1 to submit straight away.

  1. Shortcuts → + → name it “Unplugged log”.
  2. Add Get App & Website Data (Screen Time action, new in iOS 26) for Today. If your phone doesn't show this action, skip to step 5 — the page works fine typed by hand.
  3. From its result, take the total screen time and convert to minutes (Calculate ÷ 60 if it returns seconds). Optionally Filter/Repeat with Each over apps and add up TikTok/Instagram/Snapchat… into a “social” variable, Messages/WhatsApp/FaceTime into “messaging”, and Maps/Spotify/Fitness into “healthy”.
  4. Add Text: with the variables inserted (whole numbers only).
  5. Add Open URLs with that text. Review the form, tap Submit.
  6. Optional: Automation → Time of Day 9:30 PM → run “Unplugged log”.

Honest status: the Shortcut flow hasn't been tried on a real iPhone. Apple's exact output fields for “Get App & Website Data” (seconds vs. a duration, whether per-app items are available, whether it works in an automation without unlocking) are unverified, so expect to tweak steps 3–4. The manual form above is the dependable path.
